WG Tunnel

APT repository

Official WG Tunnel builds for Debian/Ubuntu. Add this repo once to get both wgtunnel (stable) and wgtunnel-beta packages you can install independently, side by side, straight from the developer via apt.

Add this repository

  1. Import the signing key.
  2. Add the repository (one source works for both packages).
  3. Install whichever you want with apt.

1. Import the signing key:

curl -fsSL https://apt.wgtunnel.com/wgtunnel-archive-keyring.asc | \ sudo gpg --dearmor -o /usr/share/keyrings/wgtunnel-archive-keyring.gpg

2. Add the repository:

echo "deb [signed-by=/usr/share/keyrings/wgtunnel-archive-keyring.gpg] https://apt.wgtunnel.com stable main" | \ sudo tee /etc/apt/sources.list.d/wgtunnel.list

3. Install - stable, beta, or both:

sudo apt update sudo apt install wgtunnel # stable sudo apt install wgtunnel-beta # beta - installs alongside stable
